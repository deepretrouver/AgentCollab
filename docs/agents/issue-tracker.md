# Community feedback / 社区反馈

GitHub Issues is the planned public tracker. This checkout has no configured remote yet;
templates are prepared locally and do not imply that a public repository or support service exists.
计划使用 GitHub Issues；当前尚无远程仓库，模板只在本地准备，不代表已发布。

Use `.github/ISSUE_TEMPLATE/bug_report.md` for failures, `feature_request.md` for suggestions,
and `.github/pull_request_template.md` for contributions. Existing labels are not created or
overwritten by this change. There is no scheduled PR-monitoring automation.
使用问题/建议模板及 PR 模板；本轮不建立或覆盖标签，不配置定期 PR 监控。

Reports should separate observed symptoms from inferred causes, and identify Server, Client,
CLI and OS versions. Keep private data and credentials out of public reports.
反馈区分实际现象与推测原因，提供版本信息，并移除私人数据和凭证。

A private vulnerability reporting channel must be verified when the repository is created.
Do not claim it is enabled before that verification; do not request exploit details in public Issues.
建库时需确认私密漏洞反馈渠道是否可用；未确认前不能宣称已启用，不在公开 Issue 中索取利用细节。
