# AgentCollab 协作控制面

本文件定义跨真人、跨电脑、跨 Agent 协作时唯一的数据和交互模型。办公室、结构看板、执行时间线、聊天和产物页只是同一模型的不同视图，不得各自维护任务状态。

## 一条工作如何流转

```text
真人原文
  -> CollaborationEnvelope
  -> Hub 持久化 Task / WorkItem
  -> Runner 领取并启动真实 CLI Agent
  -> 原生执行状态与凭证
  -> 群聊可见交付
  -> AI 审查（文件修改任务）
  -> 真人决定合并或退回
  -> 合并后独立校验
  -> 验收完成
```

任务只有在群聊出现可见交付后才算交付。Runner 的退出码、内部编排提示词或任务状态不能替代用户可见结果。

## 消息信封

Hub 向 Runner 下发的 `CollaborationEnvelope` 使用持久化任务 ID 作为幂等键，并包含：

- `conversation`：原始话题 ID；
- `in_reply_to`：本次委托依据的消息；
- `from` / `to`：发起人和目标 Agent；
- `act`：当前为 `request`；
- `hops`：跨 Agent 转交深度，用于限制循环；
- `requires_reply`：是否必须形成可见回复；
- `needs_human`：是否升级到真人处理。

重试不得生成新的信封 ID。重复领取、网络恢复和 Client 重连都必须保持同一关联链。

## 三种协作视图

- **总办公室**：在同一张楼层图中展示全部步骤区域、真人座位、名下 Agent 工位、中央收件台和公共档案柜；右侧总控台统一处理异常、验收和最近流转，适合快速理解和调度。步骤只是同一项目中的工作区域，不代表各自复制一套项目。
- **结构看板**：编辑步骤、负责人、权重、目录、状态，执行 AI 审查、合并和退回，适合精确管理。
- **执行时间线**：展示排队、Runner 领取、原生执行、交付、审查、合并和验收记录，适合排错和审计。

三种视图只能调用相同的 API，不能通过前端动画自行推断或修改后台状态。

## Git Broker

Agent 可以修改任务临时副本或负责人本机目录，但不能直接覆盖团队正式版本。Hub 是共享 Git 的唯一提交代理：

1. 负责人提交候选目录；
2. Hub 建立隔离分支并生成差异；
3. AI 主审解释改动并运行验证；
4. 管理员决定合并或退回；
5. Hub 合并到受保护主分支；
6. 另一 Agent 做合并后校验；
7. 校验通过后事项完成。

## 共享记忆

第一层共享记忆由 Hub 从结构化事实自动生成：项目目标、当前步骤、步骤说明和状态。Runner 每次领取步骤任务时自动获得这份快照。

知识库文件保持独立来源和权限：

- 工作区共享资料：同一工作区的群聊可引用；
- 本群资料：只在当前群聊引用；
- 步骤正式版本：公共底稿的冻结版本；
- 负责人本机目录：只用于明确选择“负责人本机最新进展”的任务。

后续记忆摘要必须保存来源消息、步骤、创建人和更新时间；检索结果不能脱离这些来源单独成为事实。

## 待我处理

以下事件统一进入协作台的待处理区：

- 文字或文件交付待验收；
- AI 审查要求修改；
- 合并冲突；
- 合并后校验失败；
- Agent 执行失败或阻塞；
- 已逾期且尚未完成的事项。

普通聊天、已完成事项和正常运行中的任务不计入待处理数字。

这里的“事项”必须满足至少一项：用户明确使用“结构化任务”创建，或会话已经归入项目步骤。普通 @ 点名、报数、自我介绍、连接排查和本地身份验证即使产生了 Agent 执行记录，也只留在聊天审计中，不进入总控台、风险列表、执行时间线或正式交付。

“待我处理”数字必须可点击，并直接切换右侧总控台的待处理清单。用户不应依靠向下滚动寻找验收入口。

从总控台、总览或产物跳回原话题时，话题详情应自动展开：正式文字或文件交付显示“验收通过 / 退回修改”；未成功且无需继续的正式事项可“关闭事项”；历史普通会话可“标记已处理”。这些处置只结束项目跟踪，不删除原消息、Agent 回复和执行凭证。

## 事项详情

总办公室中的工作事项统一使用右侧抽屉下钻，按四个层次展示：

- **业务**：所属步骤、当前阶段、执行人、交付数量和状态；
- **执行链路**：发起、Agent 执行、可见交付与验收节点；
- **Git 与验收**：任务分支、AI 审查、合并和合并后校验；
- **共享上下文**：本次任务取得的项目目标、步骤说明、公共底稿、本机绑定状态和知识库范围。

普通用户默认只看业务内容。内部提示词、幂等键和完整消息信封只允许在高级诊断中查看，不能替代或改写用户原文。
